# HiSpark

HiSpark 是由海思技术有限公司主导的开源开发者社区，为开发者提供 SDK、工具链、开发环境、文档与解决方案，与广大开发者共建万物互联的智能世界。

This GitHub organization hosts public mirrors of the HiSpark open-source repositories on GitCode. The GitCode repositories remain the primary source for development, issues, pull requests, releases, and community governance.

## 快速入口

- [HiSpark GitCode 主页](https://gitcode.com/HiSpark)
- [海思开发者社区](https://developers.hisilicon.com/forum/all)
- [HiSpark 社区文档](https://gitcode.com/HiSpark/docs)

## 镜像说明

这些仓库用于扩大开源代码的可发现性和获取渠道。每个镜像仓库的主页均指向对应 GitCode 源仓库；许可条款、版本说明和贡献要求以各项目及 HiSpark GitCode 社区发布的信息为准。

问题反馈与代码贡献请优先前往对应的 [GitCode 源仓库](https://gitcode.com/HiSpark)。
